Text field with a hairline border and coral focus ring; monospace value to match the editor feel.

```jsx
<Input placeholder="Search notes…" prefix={<SearchIcon />} />
<Input size="sm" defaultValue="10.1.20.15" />
<Input invalid placeholder="Required" />
```

Sizes `sm`/`md`/`lg`; `prefix` for a leading icon; `invalid` for the danger state.

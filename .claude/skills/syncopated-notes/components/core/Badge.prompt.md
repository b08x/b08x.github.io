Small uppercase status pill in the editor status palette; use for arXiv-style labels, note status, counts, and inline metadata.

```jsx
<Badge tone="info">note</Badge>
<Badge tone="success" solid>done</Badge>
<Badge tone="danger">error</Badge>
<Badge tone="coral">draft</Badge>
```

Tones: `neutral` `info` `accent` `success` `question` `warning` `danger` `special` `coral`. Default is tinted-soft; pass `solid` for a filled pill.
